# BW2 — редизайн boringwelding.com

Статический сайт НПК «Механик». Без сборки, без зависимостей — открывается напрямую в браузере.

## Дизайн-система

Вариант A — **Swiss Modernism 2.0** (подобран через ui-ux-pro-max).

| Токен | Значение | Назначение |
|---|---|---|
| `--ink` | `#0A0A0A` | Основной текст, кнопки |
| `--ink-2` | `#3D3D3D` | Вторичный текст |
| `--ink-3` | `#6E6E6E` | Подписи, метки |
| `--paper` | `#FFFFFF` | Фон |
| `--paper-2` | `#F5F5F4` | Фон секций и медиа-плашек |
| `--line` | `#E5E5E5` | Хайрлайны сетки |
| `--accent` | `#E11D2E` | Единственный акцент (фирменный красный) |
| `--accent-ink` | `#B8121F` | Акцент в мелком тексте (контраст 5.4:1) |

- Шрифт: **Inter** 400/500/600/700, `font-variant-numeric: tabular-nums` для характеристик
- Сетка: строгие 12 колонок, базовый юнит 8px, разделители 1px вместо теней
- Типографика: `clamp()` — от 375px до 1440px без промежуточных брейкпоинтов
- Анимация: 200 мс, только `opacity`/`transform`, полное уважение `prefers-reduced-motion`

## Структура

```
index.html                  главная (hero, конструкция, каталог, видео, опции, география, форма, контакты)
models/*.html               10 карточек станков — генерируются
build_models.py             генератор страниц моделей (данные + шаблон)
assets/css/style.css        дизайн-токены и все стили
assets/js/main.js           меню, фильтр каталога, reveal, валидация формы, маска телефона
```

### Пересборка страниц моделей

Правите данные в `MODELS` внутри `build_models.py`, затем:

```bash
python3 build_models.py
```

## Что нужно доделать перед продом

1. **Форма заявки** — `assets/js/main.js`, комментарий «Точка интеграции»: подставить реальный endpoint (CRM / почта / Telegram-бот). Сейчас имитация отправки.
2. **Изображения** — временно ведут на Tilda CDN (`static.tildacdn.com`). Перед запуском выгрузить в `assets/img/` и перевести в WebP/AVIF.
3. **Видео** — карточки в секции «Видео» ведут на форму. Подставить ссылки на YouTube / VK / Rutube.
4. **Юридические страницы** — политика конфиденциальности, пользовательское соглашение, согласие на обработку ПД.
5. **Аналитика** — Яндекс.Метрика / Google Analytics.

## Доступность

- Контраст текста ≥ 4.5:1, крупного ≥ 3:1
- Все интерактивные элементы ≥ 44×44 px
- Видимый focus-ring, skip-link, корректный порядок заголовков
- Форма: видимые лейблы, ошибки рядом с полем, `aria-live`, автофокус на первом невалидном поле
- `prefers-reduced-motion` отключает все переходы

## Совместимость

Проверено на брейкпоинтах 375 / 768 / 1024 / 1440. Поддержка: Chrome, Safari, Firefox, Edge (последние 2 версии).
